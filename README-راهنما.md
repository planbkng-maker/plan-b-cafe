# راهنمای راه‌اندازی سایت PLAN B

این پوشه شامل سایت منو (`index.html`) و پنل مدیریت (`admin.html`) است.
هر دو به یک دیتابیس رایگان و واقعی به نام **Firebase** وصل می‌شوند تا
هر تغییری که در پنل مدیریت بدهی، همان لحظه روی سایت اصلی هم دیده شود.

فقط کافیست مراحل زیر را **یک‌بار** انجام بدهی (حدود ۱۵ دقیقه، بدون نیاز
به برنامه‌نویسی). بعد از آن، همیشه از طریق `admin.html` همه‌چیز را
مدیریت می‌کنی.

---

## مرحله‌ی ۱ — ساخت پروژه‌ی رایگان Firebase

1. به آدرس **console.firebase.google.com** برو و با جیمیل خودت وارد شو.
2. روی «Add project / افزودن پروژه» بزن، اسمش را مثلاً `plan-b-cafe`
   بگذار و ادامه بده (Google Analytics را می‌توانی خاموش کنی، لازم نیست).
3. بعد از ساخته‌شدن پروژه، وارد صفحه‌ی آن شو.

## مرحله‌ی ۲ — فعال‌سازی سرویس‌ها

از منوی سمت راست (Build):

- **Firestore Database** → Create database → حالت production را انتخاب کن → یک منطقه (Location) نزدیک انتخاب کن → Enable.
- **Storage** → Get started → همان تنظیمات پیش‌فرض → Done. (این برای ذخیره‌ی عکس آیتم‌ها است.)
- **Authentication** → Get started → از تب Sign-in method گزینه‌ی **Email/Password** را فعال کن.
  سپس در تب **Users** یک کاربر بساز (ایمیل و رمز عبور خودت) — همین ایمیل/رمز برای ورود به `admin.html` استفاده می‌شود.

## مرحله‌ی ۳ — گرفتن کلیدهای پروژه

در صفحه‌ی اصلی پروژه، روی آیکون **⚙️ Project settings** بزن.
پایین صفحه، بخش «Your apps» را پیدا کن و روی آیکون **</>  (Web)** بزن،
یک اسم دلخواه بده و Register کن. یک قطعه‌کد با مقادیری شبیه این به تو
نشان می‌دهد:

```
apiKey: "...",
authDomain: "...",
projectId: "...",
storageBucket: "...",
messagingSenderId: "...",
appId: "..."
```

این مقادیر را داخل فایل **firebase-config.js** (همین پوشه) به‌جای
`PASTE_YOUR_...` بگذار و ذخیره کن. همین یک فایل تنها جایی است که باید
دستی ویرایش کنی.

## مرحله‌ی ۴ — تنظیم دسترسی‌ها (Security Rules)

### Firestore Rules
در بخش Firestore Database → تب **Rules**، محتوا را با این جایگزین کن:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

(یعنی: همه می‌توانند منو را بخوانند، ولی فقط کاربر لاگین‌کرده — یعنی تو
از طریق پنل مدیریت — می‌تواند تغییر بدهد.)

### Storage Rules
در بخش Storage → تب **Rules**، همین منطق را بگذار:

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

بعد از هرکدام، دکمه‌ی **Publish** را بزن.

## مرحله‌ی ۵ — تست روی گوشی/کامپیوتر خودت

فایل `index.html` را مستقیم در مرورگر باز کن تا مطمئن شوی وصل شده.
سپس `admin.html` را باز کن، با ایمیل/رمزی که در مرحله‌ی ۲ ساختی وارد شو،
روی «افزودن داده‌ی نمونه» بزن تا چند دسته‌بندی و آیتم آزمایشی ببینی،
و از همان‌جا شروع به ویرایش/افزودن اطلاعات واقعی کافه کن.

---

## مرحله‌ی ۶ — گرفتن آدرس اینترنتی رایگان با اسم PLAN B

ساده‌ترین راه، سرویس رایگان **Netlify** است (نیاز به دانش فنی ندارد):

1. به آدرس **app.netlify.com/drop** برو.
2. کل پوشه‌ی این پروژه (همان پوشه‌ای که `index.html` توش هست) را با
   موس بکش و همان‌جای صفحه رها کن (Drag & Drop).
3. ظرف چند ثانیه یک آدرس رایگان می‌سازد. برای اینکه اسم PLAN B داخلش
   باشد: وارد **Site settings → Change site name** شو و مثلاً
   بنویس `planb-cafe` — آدرس نهایی می‌شود:

   **https://planb-cafe.netlify.app**

   (اگر این اسم گرفته شده بود، مثلاً `planb-cafe-menu` را امتحان کن.)

همین! از این به بعد، هر بار که از طریق `admin.html` چیزی را تغییر
بدهی، چون داده از Firebase خوانده می‌شود، نیازی به آپلود دوباره‌ی سایت
نیست — تغییرات بلافاصله روی همان آدرس دیده می‌شود.

> نکته: اگر بعداً خواستی یک دامنه‌ی اختصاصی واقعی (مثل planbcafe.com)
> بخری و وصل کنی، از همان تنظیمات Netlify → Domain management هم
> امکان‌پذیر است.

---

## خلاصه‌ی فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | سایت اصلی که مشتری با اسکن QR می‌بیند |
| `admin.html` | پنل مدیریت — ورود با ایمیل/رمز |
| `firebase-config.js` | تنها فایلی که باید با کلیدهای خودت پر کنی |
| `styles.css` | رنگ‌بندی و ظاهر کلی — پسته‌ای/کرم با تم کاکتوس |
| `main.js` / `admin.js` | منطق برنامه — نیازی به تغییر نیست |

اگر جایی گیر کردی یا خواستی بخشی از طراحی/رنگ‌ها تغییر کند، همین‌جا بگو.
